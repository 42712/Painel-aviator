Caçador de URL WebSocket

Use este script para capturar a URL do WebSocket de qualquer casa de aposta com Aviator.

Passo 1: Copie o script abaixo

// COLE ESTE CÓDIGO NO CONSOLE (F12) DO NAVEGADOR
// enquanto estiver na página do jogo Aviator

(function() {
    const urls = new Set();
    const OrigWS = window.WebSocket;
    
    window.WebSocket = function(url, protocols) {
        if (!urls.has(url)) {
            urls.add(url);
            console.log('%c🔗 WEBSOCKET CAPTURADO!%c',
                'color:#22c55e;font-size:18px;font-weight:bold', '');
            console.log('%c' + url + '%c',
                'color:#ff2f92;font-size:16px', '');
            console.log('%cCopie a URL acima para o config.json%c',
                'color:#f59e0b;font-size:14px', '');
            console.log('');
        }
        return new OrigWS(url, protocols);
    };
    window.WebSocket.prototype = OrigWS.prototype;
    
    console.log('%c✅ Monitor ativo! Recarregue a página (F5) do jogo.%c',
        'color:#22d3ee;font-size:16px;font-weight:bold', '');
    console.log('%cQuando o jogo conectar, a URL aparecerá aqui.%c',
        'color:#94a3b8', '');
})();

Passo 2: Abra o site da casa de aposta

Ex: SorteNaBet, BravoBet, Blaze, Stake, Betano, etc.
Navegue até o jogo Aviator.

Passo 3: Pressione F12 e cole o script

Aperte F12 → aba Console
Cole o script copiado e pressione Enter

Passo 4: Recarregue a página do jogo

Aperte F5 para recarregar.
O script vai capturar a URL do WebSocket e mostrar no console em rosa.

Passo 5: Configure o coletor

Abra o arquivo C:\PROJETOS\painel-aviator-jhow\coletores\config.json

Cole a URL capturada no campo "ws_url" e mude "ativo" para true:

{
  "casas": [
    {
      "nome": "NOME DA CASA AVIATOR",
      "ws_url": "wss://..." ← COLE A URL AQUI,
      "provider": "auto",
      "ativo": true              ← MUDE PARA true
    }
  ]
}

Passo 6: Reinicie o painel

Pare o servidor (Ctrl+C) e execute novamente:

C:\PROJETOS\painel-aviator-jhow\run.bat

O coletor vai conectar direto no WebSocket e começar a salvar todas as rodadas!

Método Alternativo (DevTools)

1. F12 → aba Network
2. Clique no filtro WS (WebSocket)
3. Recarregue a página (F5)
4. Clique na conexão que aparece → copie a Request URL
5. Cole no config.json
