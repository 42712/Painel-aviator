1. COMO O PAINEL FUNCIONA

1.1 Arquitetura Geral

[ Casas de Aposta ] ---- WebSocket/HTTP ----> [ PAINEL ] ---- Flask/API ----> [ Dashboard Web ]
      |                                              |                              |
  Gera dados                                    Coleta & Armazena              Exibe análises
  das rodadas                                   no banco SQLite                (gráficos/tabelas)

1.2 Tecnologias Utilizadas

1.3 Ciclo de Vida de uma Rodada

Tempo 0s  → Apostas abertas
Tempo 5s  → Apostas fecham
Tempo 8s  → Multiplicador começa a subir (1.00x → 2.00x → 5.00x ...)
Tempo Xs  → Multiplicador ESTOURA (ex: 3.47x)
          → Dados enviados via WebSocket para todos os clientes
          → Painel captura: round_id, multiplier, timestamp
          → Nova rodada começa em 5 segundos
Tempo médio entre rodadas: Aproximadamente 18-20 segundos (dependendo da casa de aposta).

2. FONTES DE DADOS - APIs PÚBLICAS

2.1 Como os dados são acessados

As casas de aposta transmitem os resultados do Aviator publicamente para que os jogadores vejam o histórico do jogo. O painel se conecta nesses mesmos canais públicos para coletar dados. O painel não hackeia, não invade e não altera nada. Ele apenas lê dados que já são transmitidos abertamente.

3.2 Versão Local (seu PC - C:\PROJETOS\painel-aviator-jhow)

A versão local funciona como proxy: quando você acessa o dashboard, ele:

1. Tenta buscar dados novos do site oficial (proxy HTTP)
2. Se o site estiver online → exibe dados reais em tempo real
3. Se o site estiver offline → usa os dados salvos no banco SQLite local
4. Cada dado novo é armazenado no banco local automaticamente (cache)

SELECT * FROM rounds 
WHERE date(captured_at) = '2026-07-26' 
ORDER BY multiplier DESC

-- Contar quantas rodadas cada casa tem
SELECT casa, COUNT(*) as total FROM rounds GROUP BY casa;

SELECT 
  substr(time_label, 1, 2) as hora,

5.2 Como Interpretar os Gráficos

Multiplicadores baixos (1.00x - 2.00x): Representam ~55% das rodadas. Cor azul.

Multiplicadores médios (2.00x - 10.00x): Representam ~35% das rodadas. Cor roxa.

Multiplicadores altos (10.00x+): Representam ~10% das rodadas. Cor rosa.

Extremos (100x+): Raros, ~1-2% das rodadas. Oportunidades de alto lucro.

import json
import sqlite3

def on_message(ws, message):
    data = json.loads(message)
    # Salvar no banco
    conn = sqlite3.connect('painel_aviator.db')
    conn.execute(
        "INSERT INTO rounds (casa, round_id, multiplier, time_label, captured_at) "
        "VALUES (?, ?, ?, ?, ?)",

    print("Conectado!")

    on_message=on_message,

9. ANÁLISE ESTATÍSTICA

9.1 O que o Painel Analisa

  • Tendência de horário: Em quais horas saem mais multiplicadores altos
  • Repetição de valores: Mesmo multiplicador saindo várias vezes seguidas
  • Afastamento: Tempo entre velas altas (ex: quanto tempo desde o último 10x+)
  • Média móvel: Média dos últimos N multiplicadores
  • Distribuição: Porcentagem de cada faixa de multiplicador

9.2 Estratégias de Aposta (uso informativo)

EstratégiaDescriçãoRisco
Baixa (1.5x)Apostar sempre em 1.5x. Alta taxa de acerto.Baixo
Média (3x-5x)Analisar tendências para entrar em 3x-5x.Médio
Alta (10x+)Esperar períodos de "seca" e apostar na saída.Alto
MartingaleDobrar aposta após cada perda. NÃO recomendado.MUITO ALTO
ALERTA: Nenhuma estratégia garante lucro. O Aviator usa RNG (Random Number Generator - Gerador de Números Aleatórios) certificado. Cada rodada é independente da anterior. Use o painel como ferramenta de análise, não como "garantia de ganho".

10. PERGUNTAS FREQUENTES

P: O painel consegue prever o próximo multiplicador?
R: Não. O jogo usa RNG certificado. O painel analisa padrões históricos, mas cada rodada é aleatória.

P: O painel é legal?
R: Sim. Ele apenas coleta dados públicos que qualquer pessoa pode ver no navegador. É uma ferramenta de análise estatística.

P: Posso usar o painel sem internet?
R: Sim, usando os dados salvos no banco local. Mas para dados em tempo real, precisa de internet.

P: Como adicionar mais casas de aposta?
R: Capture a URL do WebSocket via F12 no navegador e configure no código (seção 8).

P: O painel faz apostas automaticamente?
R: Não. Ele é apenas uma ferramenta de visualização/análise. Não automatiza apostas.

12.5 Como Adicionar uma Nova Casa no Painel

// 1. Capture a URL do WebSocket via F12 (seção 12.3)

// 2. Crie o arquivo: C:\PROJETOS\painel-aviator-jhow\coletores\nova_casa.py

import websocket
import json
import sqlite3

WS_URL = "wss://api.dacasa.com/aviator/ws"  # URL capturada via F12
NOME_CASA = "Nome da Casa Aviator"

conn = sqlite3.connect('painel_aviator.db')

def on_message(ws, message):
    data = json.loads(message)

    // Adapte a extração dos campos conforme o formato
    if data.get('type') == 'crash':        # Formato Spribe
        round_id = data['round_id']
        multiplier = data['crash_point']
        ts = data.get('timestamp', 0)

        from datetime import datetime
        dt = datetime.fromtimestamp(ts)
        time_label = dt.strftime('%H:%M:%S')
        captured_at = dt.strftime('%Y-%m-%dT%H:%M:%S')

        conn.execute(
            "INSERT OR IGNORE INTO rounds (casa, round_id, multiplier, time_label, captured_at) "
            "VALUES (?, ?, ?, ?, ?)",
            (NOME_CASA, str(round_id), round(multiplier, 2), time_label, captured_at)
        )
        conn.commit()
        print(f"[{NOME_CASA}] #{round_id} = {multiplier}x")

def on_open(ws):
    print(f"[{NOME_CASA}] Conectado!")

def on_error(ws, error):
    print(f"[{NOME_CASA}] Erro: {error}")

ws = websocket.WebSocketApp(WS_URL,
    on_message=on_message,
    on_open=on_open,
    on_error=on_error
)
ws.run_forever()

12.7 Script Automatizado para Capturar URLs WebSocket

// Script auxiliar: cole no Console do navegador (F12) enquanto
// estiver na página do jogo Aviator para capturar a URL do WebSocket

(function() {
  const originalSend = WebSocket.prototype.send;
  const connections = [];

  // Intercepta TODAS as conexões WebSocket da página
  const OrigWebSocket = window.WebSocket;
  window.WebSocket = function(url, protocols) {
    console.log('%c[WEBSOCKET CAPTURADO]%c ' + url,
      'color:#22c55e;font-weight:bold', 'color:#fff');

    connections.push({
      url: url,
      time: new Date().toLocaleTimeString()
    });

    return new OrigWebSocket(url, protocols);
  };

  console.log('%cMonitor de WebSocket ativo!%c',
    'color:#f59e0b;font-size:16px', '');

  // Depois de 1 minuto, mostra todas as URLs capturadas
  setTimeout(() => {
    console.log('%c=== URLs CAPTURADAS ===%c',
      'color:#ff2f92;font-size:16px', '');
    connections.forEach((c, i) => {
      console.log(`%c${i+1}.%c ${c.url}`,
        'color:#22d3ee', 'color:#fff');
    });
  }, 60000);
})();

// Cole este código no Console (F12) e recarregue a página do jogo.
// Em 1 minuto você verá todas as URLs WebSocket capturadas.
